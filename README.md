# CloudBlitz GenAI Placement Training Portal

A static, responsive classroom portal for GenAI placement readiness. It includes the 12-day GenAI roadmap, Trainer Mode, project SOP, workbook explorer, GenAI resume examples, profile guidance, and interview preparation.

## Live portal

After publishing this repository with GitHub Pages, the portal will be available at:

[https://rushidholecom.github.io/GenAI-Placement-Training-Portal/](https://rushidholecom.github.io/GenAI-Placement-Training-Portal/)

## Run locally

Open `index.html` in a browser, or run `node local-server.mjs` and visit `http://localhost:8000`.

## Training content

- GenAI career readiness, job roles, resumes, and professional profiles
- LLM foundations and prompt engineering
- RAG, embeddings, vector databases, and retrieval evaluation
- Agents, tool calling, system design, and responsible AI
- End-to-end GenAI project planning, build, validation, and handover
- GenAI technical interview practice and communication

The portal uses static HTML, CSS, and JavaScript. Training progress and profile checklist states are stored in the current browser.
